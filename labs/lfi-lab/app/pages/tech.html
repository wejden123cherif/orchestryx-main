Critical Zero-Day in Router Firmware Exposes 4.2 Million Devices

By Priya S. MenonCybersecurity Reporter

Security researchers disclosed a critical unauthenticated remote code execution vulnerability affecting firmware versions 3.x through 5.2 of a widely deployed router product, with 4.2 million units currently exposed to the internet.

The flaw resides in the device's web administration interface and allows an attacker to execute arbitrary commands with root privileges by sending a single malformed HTTP request — no authentication required.

"The attack surface is trivial. The vendor must issue an emergency patch immediately." — Lead Researcher, Northfield Labs

The vendor has released a patch but auto-update is disabled by default, meaning manual intervention is required for the vast majority of installations.
