# Docs

This folder contains long-form project, architecture, roadmap, and operations documentation.

Current contents:

- `overview.md`: what Orchestryx is building and why.
- `architecture.md`: components, data flow, and system diagrams.
- `provisioning.md`: web lab lifecycle, status model, startup flow, and speed notes.
- `admin.md`: admin console access control and operating model.
- `cost-optimization.md`: implemented cost controls and next optimizations.
- `troubleshooting-provisioning.md`: runbook for slow or failed lab starts.
- `roadmap.md`: current state, next steps, and future phases.
- `aws-setup.md`: AWS infrastructure reference for the ECS deployment.
- `summary.md`: folder-level documentation.

Future use:

- Add runbooks, incident notes, architecture decision records, security reviews, and professor/team handoff documents here.
